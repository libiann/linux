1. Define Linux. 
Linux is the kernel which is the core component of an operating system.

2. What are the advantages of Linux?
Lightweight, Free, Fast startup, Real Linux commands, Works with Docker, Easy access to Windows file. 

3. Why is Linux widely used in DevOps?
Because most production servers are Linux.

4. Explain the difference between Linux and Ubuntu.
Linux is the kernel which is the core component of the operating system and Ubuntu is a Linux distribution built on top of the Linux kernel and includes additional software, package management tools, and a user interface, making it a complete operating system.

5. What is a Linux Distribution?
A Linux distribution is a complete operating system built using the Linux kernel,along with other software, tools, libraries and  a package manager.

6. What is Ubuntu?
Ubuntu is a Linux distribution built on the top of the Linux kernel.

7. What is WSL?
Window Subsystem for Linux used to run Ubuntu Linux directly inside Windows.

8. Explain the relationship between Windows, WSL, and Ubuntu.
we can run Ubuntu in windows directly using WSL.

9. Why do Windows users install Ubuntu through WSL?
Windows users install Ubuntu through WSL because it allows them to use a Linux environment directly inside Windows without installing a separate Linux operating system.

10. Explain how WSL helps developers.
Developers can use WSL to run Linux commands and development tools on Windows without installing Linux separately.
