Task 5 — Numeric Permission Conversion
Convert rwxrwxrwx, rwxr-xr-x, rw-r--r--, rw-------, r-xr-xr-x to numeric values.
rwxrwxrwx -> 777
rwxr-xr-x -> 755
rw-r--r-- -> 644
rw------- -> 600
r-xr-xr-x -> 555

Explain why 777 is dangerous and why 600 is recommended.
Permission 777 means everyone has full permissions on the file or directory.
Permission 600 means only the owner can read and write the file.

Task 6 — chmod Practical
Apply chmod 777, 644, and 600 to project.txt and explain results.
777 means owner,group and others have the permission to read, write and execute.
644 means owner has the permission to read and write while group and others have the permission to read only.
600 means the owner has the permission to read and write while the group and others have no permission.

Task 10 — Sudo Verification
Run sudo whoami and sudo -l.
Explain sudo and why it is preferred over root login.
sudo allows a user to execute commands with administrator privileges.It is preferred over root login because it provides better security, controlled access, command logging and accountability. It also reduces the risk of accidental system-level changes.


Real DevOps Scenario
deploy.sh → executable
config.env → owner only
application.log → owner write, others read
Assign correct permissions and justify.
deploy.sh(executable deployment script) can have the permission 755 means -rwxr-xr-x which means the owner can read, write and execute the file while group and others can read and execute only.
config.env(sensitive configuration) can have the permission 600 means -rw------- which means the owner can read and write while group and others don't have any permission. because configuration files may contain database passwords, API keys and other secrets.Only the owner should be able to access them.
application.log(owner write,others read) can have the permission 644 means -rw-r--r-- which means owner can read and write while group and others can read only. the owner can update the log file, while other users can read it without modifying it.
