1. Create a new user called devopsuser.
   sudo useradd -m devopsuser

2. Verify that the user devopsuser has been created successfully.
   id devopsuser

3. Create a new group called devops.
   sudo groupadd devops

4. Add devopsuser to the devops group.
   sudo usermod -aG devops devopsuser

5. Verify the group membership of devopsuser.
   groups devopsuser

6. Create a directory called project_data.
   mkdir project_data

7. Change the ownership of project_data to devopsuser.
   sudo chown devopsuser project_data

8. Change the group ownership of project_data to devops.
   sudo chown devopsuser:devops project_data

9. Verify the ownership and permissions of project_data.
   ls -ld project-data

10. Create a file called project.txt inside project_data.
    touch project.txt

11. Assign ownership of project.txt to devopsuser and devops group.
    sudo chown devopsuser:devops project_data/project.txt

12. Verify the ownership details of project.txt.
    ls -l project_data/project.txt

13. Delete the project.txt file.
    sudo rm project_data/project.txt

14. Remove the project_data directory.
    rmdir project_data

15. Delete the devopsuser user.
    sudo userdel devopsuser

16. Delete the devops group.
    sudo groupdel devops
